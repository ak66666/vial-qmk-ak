# ThumbsUp! v5/v8/v11 for AtMega32U4 ProMicro

![v11 complete with MX switches and caps](https://github.com/ak66666/ThumbsUpV11_5x12_KailhChoc_MX_ProMicro/blob/main/Photos/IMG_20250606_115846720.jpg)
![v11 complete with Kailh Choc switches and caps](https://github.com/ak66666/ThumbsUpV11_5x12_KailhChoc_MX_ProMicro/blob/main/Photos/IMG_20250606_113335330.jpg)

A yet another version of the ThumbsUp! keyboard, a three-level PCB-based keyboard supporting Kailh Choc (1350) and Cherry MX-compatible switches.
This v11 version got 5x12 key layout with 3-key thumbcluster and an optional touchpad.


* Keyboard Maintainer: [Alexander (Sasha) Karmanov](https://github.com/ak66666)
* Hardware Supported: AtMega32u4 ProMicro-compatibles
* Hardware Availability: https://www.etsy.com/ca/listing/1482981916

Make example for this keyboard (after setting up your build environment):

    make thumbsup/rev11_promicro_5x12:default

Flashing example for this keyboard:

    make thumbsup/rev11_promicro_5x12:default:flash

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).

## Bootloader

Enter the bootloader:

* **Physical reset button**: Press twice the button on the bottom side of the middle PCB.
